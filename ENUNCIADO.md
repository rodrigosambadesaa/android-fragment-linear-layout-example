# Material de partida — Fragment añadido a un LinearLayout

Ejemplo docente de 2019 sobre **Fragments** en Android.

El objetivo es crear un `Fragment` por programación e insertarlo dinámicamente en un `LinearLayout`, sin utilizar un contenedor de Fragment dedicado, para comparar esta técnica con otras formas de composición de interfaz.

La reconstrucción incorpora una interacción mínima común a los ejemplos: introducir un mensaje, pulsar **Procesar** y mostrar en el Fragment cuántos caracteres se han escrito.

Se conserva deliberadamente el `LinearLayout` como host porque es la característica que diferencia este ejemplo histórico. Para código nuevo, el propio repositorio recomienda un contenedor específico.

No existe una base de datos asociada.
